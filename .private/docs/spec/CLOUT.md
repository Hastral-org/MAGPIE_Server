# CLOUT POINTS

- gained when participating in a **Quest**[^quest]
- can be spent to use the perks of the current PLAYER role[^role]

[^quest]: Quest are 'measured-stats' game events with a **GOAL** and a **PROGRESS** — [QUEST](./quest.md)

[^role]: PLAYER roles define what the user is allowed to to do — [PLAYER roles](./role.md)
